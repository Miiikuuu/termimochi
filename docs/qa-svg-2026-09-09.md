## Boundaries

Fixtures exercise gradients, transparent/half-transparent edges, small vector
upscaling, nonzero viewBox origins, local reuse, clipping and system-font text.
Unsupported embedded images, scripts, animation, external references and DTDs
produce errors. CPU/address-space limits are configured; timeout and output-cap
behavior are exercised separately. This is not a claim of complete SVG-spec
coverage, a renderer security audit, or cross-compositor manual verification.

The user's `.bashrc`, Fastfetch configuration and saved Greeting preset remained
byte-identical through testing and installation. No Git commit or push was made.
