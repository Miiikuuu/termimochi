# 交互样板：手动验收卡

这不是命令行执行器。日常终端配置不会因为在这里输入或保存而改变。

| 操作 | 应看到的结果 |
| --- | --- |
| 打开 Kitty 或 Ptyxis 主题 | 默认 Full，有“Interactive samples · no local commands”标识，无须 Start |
| 在末尾 Prompt 后输入 `help`、`git diff` 并回车 | 命令列表、彩色差异示例和当前 Prompt；没有底部分离表单，也没有真实执行项目命令 |
| 输入 `cd src`，再留下未回车的文字 | 当前虚拟目录变成 `/demo/src`，草稿保留 |
| 点击 `+` 新建标签；输入 `cd /` 和 `clear` | 第二个标签独立变化；点击第一个标签可找回原目录、草稿和输出 |
| 在 Palette 改背景，在 Typography 改字号 | Full 不被切走，已有输出和输入历史不清空 |
| 调整 Layout → Window Top | Kitty 标签样式/位置/门槛反映实际标签；Ptyxis 只展示自身支持的样式。隐藏标签后仍可从 `…` 选择标签 |
| Kitty 主题导入 GIF，输入 `fastfetch` | 当前欢迎界面追加到输出；GIF 是设计效果，不代表协议验证 |
| 输入 `clear`，滚动、切标签、再改字号 | 清除的 GIF 不悬浮回来；其它标签的欢迎界面仍在 |
| 在 Ptyxis 主题查看同一图片设计 | Full 使用字符回退，不假装支持 Kitty 图片协议；素材编辑仍保留 |
| 输入 `git dif` 后按 Tab、按上下方向键 | 补全有限命令；浏览当前标签的命令历史 |
| 中文输入法组合、确认、Esc 取消 | 组合态回车不会执行样板动作，文字编辑交给 GTK |
| Ctrl+Shift+C/V 复制粘贴，多行粘贴 | Unicode 文本不变；多行被拒绝，绝不会自动提交 |
| 输入草稿后 Ctrl+Z / Ctrl+Shift+Z | 只撤销/重做输入，不撤销主题。切换标签后输入编辑撤销栈会清空，草稿和命令历史仍保留 |
| Ctrl+C、Ctrl+L | 无选区时取消草稿；清除输出。不会向真实进程发信号 |
| Ctrl+S 保存，关闭后重开 | 保存主题设置，不保存样板标签/命令历史；重开是一份新样板会话 |

真实使用仍走 **Use Theme…** 的目标选择、审阅和确认。**Try Greeting**
仍是欢迎界面的真实临时验证，不等于运行这里输入的命令。

启用 native-preview 的构建中，右上角高级菜单保留实验性原生预览。
它会运行真实程序，仍需明确授权。返回设计预览不等于停止已启动的原生会话；
有会话运行时标题会提示，关闭仍保留停止确认。

观察范围：建议检查 1130×830 与 2048×1126。默认 Actual size 保持主题实际字号，
随视口重排列数；100% · fixed grid 检查保存的初始列数。Fit window 对有限窗口、
顶部和输入同比缩放，长历史在内部滚动；缩放不改保存的字号或 Columns。

已执行与未执行项目请以 QA 记录为准；本卡不是“真实用户测试已通过”的声明。
