# “小猫测试”预览可达性验收卡

本卡只检查设计预览，不应用主题、不改终端配置。完整测量、自动化结果与原始截图见
[检查报告](preview-reachability-qa.md)。

## 打开

在项目目录运行 `./target/release/termimochi`，打开“小猫测试”。不要点击 Use Theme / Apply。
本轮保留了主题原值：16 pt、Greeting 占位 32 列；120×36 是当前继承的目标窗口。
不要为了放大预览先改这些数值。

如要使用隔离状态，可运行 `bash scripts/run-isolated.sh`，只打开主题副本。
隔离状态不读取日常 GSettings，因此继承的字体/窗口尺寸可能与原桌面不同；
报告中的自动化复现额外提供了同一字体和参考值，不把这种差异当成修复结果。

## 逐项操作

| 操作 | 应看到什么 |
| --- | --- |
| 保持原来窄窗口，右侧选 Full → Fit | 完整目标窗口按一个比例缩小；本机匹配复现约 33%。标题、GIF、文字一起缩放。左侧字号、Columns、Rows、图片占位不变。 |
| 切 100% · fixed grid | 字体恢复原尺寸。右侧/下方出现编辑器导航滚动条，即使主题 Scrollbar 关闭也能看到。 |
| 拖底部滚动条或横向滚动，再向下滚 | 能依次看到右边的信息值、底部完整 Prompt；不是只有截断的字段名称。 |
| 切 Actual size | 此窄窗口为图上文下。向下滚可看全部系统信息、CPU 完整型号及输入行；长字段会换行。 |
| 点击预览工具栏的向下箭头 | 回到当前输入位置；没有溢出时该按钮禁用，不改变窗口尺寸。 |
| 点击输入，键入 `help` 并回车；再输入较长文字或中文 | 仍是有限交互示例，未执行本机命令。输入位置可见，只有一个输入光标。 |
| 滚回信息/历史中段，切 Palette 改背景颜色 | 颜色更新，但不被强制拉回底部；横向位置也保留。切左侧页不切走 Full。 |
| 在历史中点击向下箭头，输入 `clear` | 清掉样例内容和 GIF 占位，输入可达；不留悬浮图片。 |
| 新建/切换预览标签；改字号、再切 Fit / Actual | 各标签输入、目录与历史独立；字体和图像共用重排与滚动几何，不以改主题数值代替缩放。 |
| 进一步收窄右侧，直到图像比观察区宽 | 即使 Actual 文本列数比 32 小，也能横向看到图像右边，不要求修改图片 Columns。 |

滚动条和“回到输入”属于编辑器，不属于目标终端外观，不会保存进主题。
Full 中 GTK 能显示 GIF 不代表 Ptyxis/Kitty 原生协议已验证；真实试用入口保持独立。

## 如还有异常

请同时截下缩放选项、左右滚动条和当前输入所在位置，并注明窗口尺寸、桌面缩放、
是否滚过历史、最后一次操作。不需要修改或重新保存主题来配合截图。

日常 Wayland/分数缩放、多显示器、IBus 和真实用户手动体验仍需验证；
隔离 X11 / 1×、2× / Fcitx 原生检查不能替代这些项目。
