# 原生内嵌预览：中文手动验收卡

这是实验功能。自动化已测到的范围和未验证项见 [测试报告](native-preview-qa.md)。
不要用工作中的真实服务、SSH、删除命令测试；临时配置不等于文件系统沙箱。

## 启动

在项目目录运行：

```bash
bash scripts/run-native-preview.sh
```

打开一个 Kitty 主题。右侧点 **Real terminal → Start native terminal**，
阅读实际命令提示后确认。Ptyxis 主题会启动项目局部构建的真实 Ptyxis，
不会借用 Kitty。缺少依赖时按提示停止，不要把启动失败当作主题失效。

## 操作卡（Kitty、Ptyxis 各做一遍）

| 操作 | 应看到的结果 |
| --- | --- |
| 输入 `pwd`，再输入 `cd /tmp`、`pwd` | 命令在右侧真实终端执行，目录变化 |
| Ctrl+Shift+T 新建标签，在两标签间切换 | 原生标签，各自保留命令和目录 |
| 中文输入法输入“你好”，看候选后提交；再输入并按 Esc 取消 | 预编辑、候选、提交与取消正确；无重复字、无残余拼音 |
| 点击左侧字体输入框，再回终端输入 | 焦点正确，没有粘住 Ctrl/Alt；这项需在你的桌面补验 |
| 输入 `top -p $$`，保持它运行，左侧改背景和字号 | 原生界面同步，top 不退出；按 Ctrl+C 后目录仍在 |
| 在终端 Ctrl+Z、Ctrl+S/Ctrl+Q | 由终端处理，不能撤销主题或弹保存窗口；Ctrl+Q 可恢复终端输出 |
| 点 Expand / Show editor，调整 App 尺寸 | 终端实际重排，不是把截图缩小；点击位置准确 |
| Ctrl+Alt+Shift+F12 或 Return to design | 回到设计预览，真实 shell 仍运行；Full/Inspect 仍能用 |
| 在 Ptyxis 原生 Preferences 改字号，等约两秒 | 提示临时差异；Resync theme 恢复当前主题，不修改设计数据 |
| 撤销左侧颜色/字号覆盖 | 回到该预览的受控基线；不是擅自读取或恢复日常配置 |
| 同时开两个 Ptyxis 主题和一个 Kitty 主题，改其中一个 | 其他窗口的颜色、字号、目标和输入不串用 |
| 点 Stop…，先取消，再确认 | 取消后继续运行；确认仅结束这个预览的标签和程序 |

## Prompt / Greeting / GIF

Kitty 主题加入 GIF 和 Prompt 后，**停止并重新开始原生预览**。
应该在真实 Kitty 中看到动画、系统信息和当前 Prompt；新标签使用同一
启动方案。运行中继续修改 Prompt/Greeting 时只提示需要重启，不能向
top/Vim/尚未提交的命令中塞入 `source`、`clear` 或 Fastfetch 命令。

Ptyxis 原生预览目前只允许字符 Greeting。选择 GIF/图片像素输出时应明确
提示不可验证、要求选择 Character 或关闭 Greeting；素材仍保留，不能
悄悄改用 Kitty，也不能用 GTK 叠图冒充。

## 仍请在你的桌面补验

- 双向复制/粘贴、中文多行和长文本；确认多行不会被拆成自动执行的命令。
- 菜单、右键、文字选择、滚动、标签关闭/新窗口、IME 切焦点。
- GNOME Wayland、125%/150% 缩放、跨屏、实际显卡环境。
- 长时间空闲/动画的 CPU、内存和输入体验。

发现问题时记录：主题目标、步骤、缩放、输入法、截图和可见错误。
不要提交真实命令历史、剪贴板敏感内容或整个环境变量。

**Save 仍只是保存主题；真实预览不会自动应用到日常终端。**
需要日常使用，回到原有使用/审阅/确认入口；本轮不替你安装或修改启动文件。
